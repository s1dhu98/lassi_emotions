# Lassi Emotions — Project Roadmap 🗺️

Welcome to the **Lassi Emotions** product roadmap! This document outlines our strategic milestones across short-term, mid-term, and long-term development cycles.

---

## 🌟 Current Release (v2.0) — *The Sentiment & Aesthetics Upgrade*

- [x] **Architecture Refactoring**: Clean ES Modules structure (`src/js/...`, `src/css/...`, `assets/...`)
- [x] **NLP Sentiment Engine**: Lexicon-based real-time sentence sentiment analysis with confidence scoring
- [x] **Mock ML Inference Service**: Simulated async deep-learning API with confidence matrices
- [x] **Interactive Customization**: Emotion Intensity slider, Wave turbulence slider, Theme switcher, Toppings overlay (Kesar, Pista, Gulab, Mango, Sprinkles)
- [x] **Internationalization (i18n)**: Bilingual UI (English + Hindi) with dynamic language toggle
- [x] **Gamification System**: Daily streak counter, achievement badges (6 unlockables), scoreboard modal
- [x] **Showcase Assets & Design**: Glassmorphism design tokens, vector SVG art banner, responsive mobile-friendly layout

---

## 🚀 Mid-Term Goals (v2.5) — *Audio & Sensor Integration*

- [ ] **WebAudio Sound Synthesis Engine**:
  - Slurp, wave ripple, and popping bubble sound effects synthesized via WebAudio API.
- [ ] **Webcam Emotion Recognition (TensorFlow.js / face-api.js)**:
  - Optional opt-in webcam mode allowing real-time facial expression tracking to automatically morph the lassi glass to match your expression!
- [ ] **Custom Recipe Card Generator**:
  - Export lassi mood combinations (e.g. "90% Joy + Saffron + Midnight Theme") as downloadable social media PNG cards.
- [ ] **Progressive Web App (PWA) Support**:
  - ServiceWorker caching & web app manifest for offline mobile installation.

---

## 🔮 Long-Term Vision (v3.0) — *3D & Spatial Experience*

- [ ] **3D WebGL Liquid Simulation (Three.js & Shaders)**:
  - Real 3D liquid fluid physics glass with refraction, ice cubes, and dynamic topping particles.
- [ ] **Multiplayer Mood Rooms (WebSockets)**:
  - Share your current lassi mood live with friends in virtual virtual rooms.
- [ ] **AR Experience (WebXR)**:
  - Place a virtual glass of emotional lassi onto your desk in Augmented Reality using WebXR!
